# StateGuard + LangGraph Integration Examples

This directory contains examples of using StateGuard with LangGraph.

## Files

- `basic_agent.py`: Minimal 15-line integration showing GuardedState + Saga inside a LangGraph node.
- `procure_guard.py`: Complex 3-agent procurement workflow with Saga compensations.

## Quick Start

```bash
pip install "stateguard-core[langgraph]"
python basic_agent.py
```
